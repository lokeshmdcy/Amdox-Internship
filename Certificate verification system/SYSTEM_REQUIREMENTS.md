# System Requirements

## Minimum Requirements

### Software
- Node.js v14.0.0 or higher
- npm v6.0.0 or higher
- MongoDB v4.4 or higher

### Hardware
- RAM: 4GB minimum (8GB recommended)
- Storage: 500MB free space
- Processor: Dual-core 2GHz or better

### Operating System
- Windows 10/11
- macOS 10.14+
- Linux (Ubuntu 18.04+, Debian, CentOS)

## Recommended Setup

### Development Environment
- VS Code or any code editor
- MongoDB Compass (GUI for MongoDB)
- Postman or Thunder Client (API testing)
- Git for version control

### Browser Compatibility
- Chrome (recommended)
- Firefox
- Safari
- Edge

## Installation Check

### Verify Node.js
```bash
node --version
# Should show v14.0.0 or higher
```

### Verify npm
```bash
npm --version
# Should show v6.0.0 or higher
```

### Verify MongoDB
```bash
mongod --version
# Should show v4.4 or higher
```

If any of these are not installed, please install them before proceeding.

## Network Requirements

- Internet connection for initial npm package installation
- Port 5000 available for backend
- Port 3000 available for frontend
- MongoDB default port 27017 (if running locally)

## Optional Tools

- MongoDB Atlas account (for cloud database)
- Heroku or Vercel account (for deployment)
- Docker (for containerization)
